\# Food Delivery Service



Система предназначена для хранения данных сервиса доставки еды.



Она содержит информацию о пользователях, ресторанах, блюдах, заказах, позициях заказов и курьерах. Система позволяет хранить сведения о заказах пользователей, составе заказов, ресторанах, из которых выполняется доставка, и назначенных курьерах.
